# 🎵 ربات ویرایشگر موزیک و ویدیو (تلگرام)

برش، تبدیل، GIF، تغییر اندازه، واترمارک، ویدیو مسیج، ویرایش تگ، ارسال به کانال با دکمه لایک، چندزبانه (فارسی/English/العربية)، سهمیه رایگان + خرید اعتبار.

## قابلیت‌ها
| قابلیت | توضیح |
|---|---|
| ✂️ برش صوت/ویدیو | با زمان `00:10 01:25` یا ثانیه |
| 🎙 mp3 ⇄ ویس | تبدیل دوطرفه (ویس = Opus) |
| 🎵 ویدیو → mp3 / 🎬 mp3 → ویدیو | با تصویر دلخواه یا پس‌زمینه‌ی مشکی |
| 🎞 ویدیو → GIF | خروجی انیمیشن تلگرام (mp4 بی‌صدا، ۱۵ ثانیه) |
| 📐 تغییر اندازه | ۱۴۴p تا ۱۰۸۰p (سقف را `MAX_HEIGHT` تعیین می‌کند) |
| 💧 واترمارک | متن (فارسی/انگلیسی با اتصال حروف) یا تصویر، ۹ موقعیت |
| ⭕ ویدیو مسیج | برش مربعی ۴۸۰×۴۸۰، تا ۶۰ ثانیه |
| 🏷 ویرایش تگ | عنوان، خواننده، آلبوم، کاور (فارسی هم درست ذخیره می‌شود) |
| 📢 ارسال به کانال | با دکمه 👍 و شمارنده‌ی لایک (هر نفر یک لایک، قابل برداشتن) |
| 💳 پرداخت | کارت‌به‌کارت با تأیید ادمین + Telegram Stars (اختیاری) |
| 🔗 ویرایش زنجیره‌ای | نتیجه‌ی هر عملیات، ورودی عملیات بعدی است |

## ⚠️ حجم فایل و رَم (مهم)
- **سرور رسمی تلگرام:** دانلود تا **۲۰MB** و آپلود تا **۵۰MB**. این محدودیت خود تلگرام است.
- **فایل تا ۱GB:** فقط با سرور محلی `telegram-bot-api` ممکن است (باید روی VPS/سرور خودت اجرا شود). بعدش در `config_local.py`: `API_BASE`، `LOCAL_API=True`، `MAX_DOWNLOAD_MB=1000`، `MAX_UPLOAD_MB=1000` را بگذار. بدون آن، همین مقدارهای ۲۰/۵۰ فعال است.
- **رَم (اندازه‌گیری‌شده):** خود ربات ≈ ۲۸–۳۶MB. ffmpeg هنگام کار جداگانه حدود ۵۰MB (صوت) تا ۱۰۰MB (ویدیو ۷۲۰p) می‌گیرد. جمع ≈ ۸۵–۱۳۵MB.
  - **۱۲۸MB:** معمولاً فقط صوت و ویدیوی کوچک؛ ویدیو ممکن است کشته شود (Out of memory).
  - **۲۵۶MB:** حداقل مطمئن. **۵۱۲MB:** راحت.
- کم‌مصرف شده: یک ffmpeg در لحظه (`MAX_JOBS=1`)، یک رشته، preset ultrafast، آپلود/دانلود استریمی (فایل کامل وارد رَم نمی‌شود).

## نصب
### ۱) تلگرام
در @BotFather ربات بساز و توکن بگیر. (`/setcommands` اختیاری: `start help lang me buy setchannel cancel`)

### ۲) تنظیمات
`config_local.example.py` را کپی کن به `config_local.py` و توکن/آیدی ادمین/کارت را بگذار. **این فایل را روی گیت‌هاب نگذار** (در `.gitignore` است).

### ۳) گیت‌هاب
```bash
cd music_editor_bot
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
مخزن را **Private** بساز.

### ۴) پنل (dash.infrlo.com یا هر پنل Pterodactyl با Python/Git)
در تب Startup:
- `GIT_ADDRESS` = آدرس مخزن، `BRANCH` = main
- `USERNAME` و `ACCESS_TOKEN` = نام کاربری گیت‌هاب و یک Personal Access Token (فقط خواندن)، `AUTO_UPDATE` = 1
- `PY_FILE` = `main.py` ، `REQUIREMENTS_FILE` = `requirements.txt`

بعد در File Manager یک فایل **config_local.py** بساز (محتوای نمونه را با توکن خودت) و Start بزن. (یا متغیرهای محیطی `BOT_TOKEN` و `ADMIN_IDS` را اگر پنل اجازه داد.)

> `requirements.txt` شامل `imageio-ffmpeg` است که یک ffmpeg آماده نصب می‌کند (حدود ۶۰–۷۰MB فضا). اگر پنل خودش ffmpeg دارد خودکار از آن استفاده می‌شود؛ یا مسیرش را در `FFMPEG` بگذار.

## دستورها
کاربر: `/start /help /lang /me /buy /setchannel /cancel`
ادمین: `/admin` • `/broadcast متن` (یا ریپلای) • `/ban id` • `/unban id` • `/addcredit id n` • `/addpremium id days`

## اعتبار و قیمت‌ها
در `config.py`: `FREE_DAILY` (سهمیه‌ی رایگان روزانه) و `PLANS` (بسته‌ها: تعداد عملیات یا اشتراک روزانه، قیمت نمایشی، قیمت به Stars).
ارسال به کانال رایگان است؛ هر عملیات ffmpeg یک واحد اعتبار می‌برد.

## ثبت کانال
`/setchannel` ← ربات را ادمین کانال کن (با اجازه‌ی ارسال پیام) و خودت هم ادمین باشی ← آیدی کانال را بفرست.

## تست
```bash
python tests/test_media.py   # عملیات واقعی ffmpeg
python tests/e2e.py          # کل ربات با تلگرام جعلی (دانلود/آپلود، پرداخت، لایک، ...)
```
(به ffmpeg روی سیستم نیاز دارد.)
